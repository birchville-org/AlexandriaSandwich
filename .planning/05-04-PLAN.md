# Plan 05-04: Web UI & Pipeline Automation Integration

<objective>
Expose the newly generated `<job>.tei.xml` and `<job>.digital.pdf` alongside the existing Sandwich PDF in the Web UI,
wire them into `scripts/run_pipeline.sh`, and update n8n workflow triggers to deliver all three core artifacts.
</objective>

## Execution Steps

1. Update `scripts/run_pipeline.sh`:
   - Add consolidation (`scripts/consolidate_book.py`), TEI export (`scripts/export_tei.py`), and Typst render (`scripts/render_digital_pdf.py`).
   - Update summary report JSON (`<job>.pipeline.json`) with `tei_xml` and `digital_pdf` paths and statuses.

2. Update `ui/main.py`:
   - Detect `<job>.tei.xml` in `/data/output/tei/` and `<job>.digital.pdf` in `/data/output/pdf/`.
   - Add routes `/download/tei/{job}`, `/download/digital/{job}`, `/preview/tei/{job}`, `/preview/digital/{job}`.

3. Update `ui/templates/job_detail.html`:
   - Add artifact section displaying the 3 core outputs:
     1. Generisches TEI-P5 (XML)
     2. 1:1 Sandwich-PDF
     3. Neusatz-PDF (Vektorschrift)
   - Include direct preview / download buttons for all 3 formats.

4. Update `workflows/n8n_ocr_pipeline.json`:
   - Verify n8n webhook reports all generated artifacts.
