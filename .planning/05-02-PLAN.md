# Plan 05-02: Generic TEI-P5 XML Exporter

<objective>
Implement a generic, standard-compliant TEI-P5 XML exporter (`scripts/export_tei.py`) that transforms
the structured book data (`book.json` / OCR coordinates) into valid academic TEI-P5 XML (Artifact 1).
</objective>

## Execution Steps

1. Implement `scripts/export_tei.py`:
   - Input: `/data/output/books/<job>/book.json` (or raw OCR outputs with page geometry).
   - Generate standard `<teiHeader>`:
     - `<fileDesc>` with `<titleStmt>`, `<publicationStmt>`, `<sourceDesc>` (linking source scan paths / IIIF manifests).
     - `<profileDesc>` with language specifications (`<langUsage>`).
   - Generate `<body>`:
     - `<pb n="[page_num]" facs="[scan_file]"/>` for every page break.
     - Section headings as `<head>`, paragraphs as `<p>`, quotes/notes as `<quote>`/`<note>`.
     - Support for structural divisions (`<div>`, `<front>`, `<body>`, `<back>`).
   - Validate XML structure (well-formedness and basic TEI-P5 schema conformity).
   - Output: `/data/output/tei/<job>.tei.xml`.

2. Test with sample multi-page jobs and verify XML validity.
