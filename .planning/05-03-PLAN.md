# Plan 05-03: Typst Typesetting Engine Integration & CLI Renderer

<objective>
Integrate Typst (modern, high-performance, LaTeX-free typesetting engine) into the worker container
and implement `scripts/render_digital_pdf.py` to compile consolidated book Markdown into a publication-grade digital vector PDF (Artifact 3).
</objective>

## Execution Steps

1. Update `docker/worker/Dockerfile`:
   - Install `typst` binary for both `linux/amd64` and `linux/arm64`.
   - Install core open-source book fonts (Linux Libertine, Source Serif Pro, DejaVu Serif, Noto Serif / Devanagari).

2. Create `templates/book.typ`:
   - Configurable margins, paper sizes (A5, B-Format, Letter).
   - Chapter headings, smart hyphenation (de, en, fr, it), page numbering, running heads.
   - Title page / half-title layout.

3. Implement `scripts/render_digital_pdf.py`:
   - Converts book structure / Markdown to Typst document.
   - Invokes `typst compile` inside worker container.
   - Output: `/data/output/pdf/<job>.digital.pdf`.
   - Emits rendering metrics (page count, execution time, fonts used).
