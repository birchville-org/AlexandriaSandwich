# Plan 05-01: Text Consolidation, Metadata & Book Structuring

<objective>
Consolidate individual per-page OCR outputs (Markdown from Mistral OCR or cleaned text from Path A hOCR)
into a unified, structured book format with metadata, headings, clean paragraph flow, and header/footer artifact removal.
</objective>

## Execution Steps

1. Create `scripts/consolidate_book.py`:
   - Input: `/data/output/markdown/<job>/` or `/data/processing/quality/<job>/*.hocr`
   - Clean page-level recurring artifacts: strip running headers, running footers, and standalone page numbers.
   - Assemble chapters, section breaks, and table of contents.
   - Inject YAML frontmatter or metadata block (Title, Author, Source Scan, Ingestion Date).
   - Output: `/data/output/books/<job>/book.md` and `/data/output/books/<job>/book.json`.

2. Test with sample multi-page jobs.
3. Hook into `scripts/run_pipeline.sh` after sandwich assembly and quality loop.
